ATLAS Feature Guide

Welcome to ATLAS. This page summarizes what the tool can analyze from Cisco DART bundles.

Bundle Intake and Preview

  • ZIP validation and extraction pipeline for DART bundles.
  • Operating system and Cisco Secure Client version preview.
  • ZTA enrollment details: org IDs, user IDs, method, and enrollment time.
  • Log timeframe summaries for ZTA, VPN, and Umbrella modules.
  • ZTA trace-level logging state detection.

ZTA Module

  • SPA and SIA mode support with scoped checks.
  • Check Inclusions or Exclusions with target evaluation (IP, FQDN, and SRV patterns).
  • Check TCP or UDP Flow with destination-port and timeframe filtering.
  • Flow visualizer grouped by destination and source-port sessions.
  • Per-transaction Initiate Analysis and transaction-level log download.
  • Check Enrollment Errors (Cert or SAML).
  • Check Configuration Sync Errors.
  • Check Server Connectivity Errors.
  • Check Trusted Network Detection.
  • Check User Pause Config.

Cached Config Analysis

  • Show complete cached-config JSON output when requested.
  • Search cached-config JSON with flow tagging (SPA or SIA) and direction context.
  • Collapse overlapping wildcard and exact FQDN hits for clearer results.

Output and UX

  • Expandable analysis output pane.
  • Transaction-focused analysis output with matching lines for selected source port.
  • Inline log download options from flow table and from result header controls.
