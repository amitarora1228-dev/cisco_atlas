Read Me — What is ATLAS?

            

                ATLAS is a local analysis tool for Cisco DART diagnostic bundles. Upload a DART ZIP exported from
                Cisco Secure Client and ATLAS parses the logs for you, turning thousands of raw log lines into
                focused, readable findings so you can troubleshoot Zero Trust Access (ZTA) and related issues faster.
            

            

                
What it analyzes

                
    
                    
  • Flow Analysis — visualizes ZTA application flows (per source port / destination) in the Visual Flow Analyzer.
    • 
                    
  • Enrollment Failures — traces SAML and Certificate-based enrollment attempts individually, with a per-attempt flow view.
    • 
                    
  • Server Connectivity Errors — surfaces proxy reachability, network-change, and pause-status transitions.
    • 
                    
  • Configuration Sync — reviews config sync requests/responses and scheduling.
    • 
                    
  • Event Viewer Logs — parses Windows Event Viewer (.evtx) entries and groups the top indicators.
    • 
                    
  • Cached Config Check — inspects inclusions/exclusions in the cached ZTA configuration.
    • 
                    
  • Trusted Network Detection (TND) — shows whether ZTA is paused on a trusted network, per proxy config, from the ZTA logs.
    • 
                    
  • User Pause Config — reports user-initiated pause settings.
    •
